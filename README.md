# Day 12 – Missing Value Identification

##  Overview

This project was completed as part of my Data Analytics Internship at Veda Technology.

The task focuses on identifying and analyzing missing values in the Titanic dataset using Python and Pandas.

##  Objective

The main objectives of this task are:

- Identify missing values in the dataset
- Count missing values in each column
- Calculate missing-value percentages
- Visualize missing values using a bar chart
- Summarize the findings

##  Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset

Titanic Dataset

##  Tasks Performed

1. Loaded the Titanic dataset using Pandas.
2. Inspected the dataset structure and columns.
3. Checked for missing values using `isnull()`.
4. Counted missing values using `sum()`.
5. Calculated the percentage of missing values.
6. Created a missing-value summary.
7. Visualized missing values using a bar chart.
8. Documented the observations and findings.

##  Key Findings

- Missing values were found in the `Age`, `Cabin`, and `Embarked` columns.
- The `Cabin` column contains the highest number of missing values.
- The `Age` column also contains a significant number of missing values.
- The remaining columns do not contain missing values.

##  Conclusion

The analysis successfully identified and summarized missing values in the Titanic dataset.

No values were removed or modified because the objective of this task was to identify and understand missing data rather than perform data cleaning or imputation.
